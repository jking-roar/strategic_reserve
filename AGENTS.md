# Project Agent Instructions

## Autonomous execution

- Act on each request immediately and carry it through to completion. Do not pause to ask whether to continue or to seek confirmation for an ordinary next step.
- When information is missing, infer a reasonable answer from the repository, the request, and established project conventions. Prefer making a reversible, well-supported assumption over blocking progress with a clarification question.
- If a material gap would benefit from multiple disciplines, use BMad Party Mode with the relevant BMad agents to fill the gap, then proceed using the best-supported conclusion. Do not use a party merely for ceremony when the answer is already evident.
- Ask the user a question only when proceeding would be impossible, unsafe, destructive, or would require inventing a critical requirement that cannot reasonably be inferred. Any higher-priority safety, security, permission, or tool-confirmation requirement still applies.
- Finish the requested work before reporting back. If assumptions or best guesses affected the result, include a clearly labeled summary of them in the final response; otherwise, do not add an assumptions section.
