updated: 2026-07-25T10:43

- (decision) Visual style: Solid colors with outlines for checkers and board elements. Clean, functional aesthetic suitable for desktop game.
- (decision) Colors: Designer to choose reasonable colors for Red/Blue checkers, board, and UI elements.
- (decision) Layout: Board centered on screen. Reserve display as counter with label (or pile of pieces).
- (decision) Interaction: Click squares or use keyboard arrows + enter/space to select. Hover outlines square being chosen.
- (decision) Accessibility: Keyboard navigation (arrows + enter/space), hover states for visual feedback. No additional accessibility requirements.
- (assumption) Color choices: Red checkers #CC0000, Blue checkers #0000CC, board background #F5F5DC (beige), grid lines #333333, legal move highlight #90EE90 (light green), target square highlight #FFD700 (gold).
- (assumption) Typography: System default sans-serif font for desktop application. Large readable text for game state, smaller for labels.
- (assumption) Layout: Main window with centered 6x6 board. Top bar: current player indicator, dice display. Bottom bar: reserve counters (Red: X, Blue: X), control buttons (New Game, Quit).
- (assumption) Checker appearance: Solid circles with black outline. Red checkers #CC0000, Blue checkers #0000CC. Size fills most of square with small padding.
- (assumption) Dice display: Two squares showing die faces (1-6 dots). Purple die on left, Green die on right. Values shown numerically and with dot patterns.
- (assumption) Reserve display: Simple counter with label 'Red Reserve: X' and 'Blue Reserve: X'. Positioned in bottom bar. Updates in real-time.
- (assumption) Game states: Main Menu (New Game, Quit), Playing (board active, dice rolling, move selection), Game Over (winner announcement, New Game option).
